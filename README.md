# 🚀 SnapCode AI Agent

**SnapCode** is an advanced, model-agnostic VS Code extension designed to bridge the gap between powerful LLMs (like Claude, ChatGPT, and DeepSeek) and your local development workspace. Instead of just chatting, SnapCode acts as an autonomous coding agent that interprets your instructions and automatically scaffolds or generates clean files directly inside your VS Code workspace.

## ✨ Key Features
* **Model-Agnostic Architecture:** Plug in your preferred AI provider and API key seamlessly.
* **Direct Workspace Integration:** Automatically generates and organizes files and directories using VS Code's native File System APIs.
* **Modern Webview UI:** Clean, intuitive developer interface right inside your editor.
* **Secure Key Management:** Designed with local security and `.gitignore` safety best practices.

## 🛠️ Tech Stack
* **TypeScript & JavaScript**
* **VS Code Extension API**
* **esbuild**
* **Webview Panel API**
